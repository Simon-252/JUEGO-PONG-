PONG

Este es el videojuego PONG para pc realizado por Lucas Olguin - Simon Garcia - Ayelen Peña - Valentina Frias
para iniciar el juego solo hay que ejecutar el archivo "main.py"
se puede jugar con 2 jugadores con las teclas "w a s d" y las flechas del teclado, o sino solo contra la computadora utilizando las flechas
en el menu de opciones se puede configurar la dificultad el oponente, velocidad de la bola y la cantidad del puntaje para ganar
